# Science arcade character source

The built-in image-generation tool created one new transparent sprite sheet using the existing `apps/web/public/games/science-lab-dash/assets/chemistry/characters.png` only as a style reference. The existing adventure artwork is unchanged. `creatures.webp` is a lossless copy of that new sheet. The runtime sheet is `apps/web/public/games/science-lab-dash/assets/arcade/creatures.png`; its twelve padded frames are packed by `node tools/build-science-arcade.cjs` using the repository’s existing Sharp dependency. Source and builder SHA-256 values are recorded in `arcade-art-data.js` and verified in tests. The renderer mirrors the slime/robot poses toward the approaching player, and keeps the guardian front-facing.

The hero, mentor and patrol use the existing adventure atlas. All remaining equipment, hazard, power-up and badge pictograms are editable vector artwork in `arcade-icons.js`, with labels supplied by the game. Original level background files remain unchanged.

## Final generation prompt

Use case: stylized-concept. Asset type: one transparent animated game sprite atlas for Science Lab Dash arcade. Input image is STYLE REFERENCE ONLY: match the glossy, carefully painted children's adventure-game rendering, crisp dark outlines, turquoise/blue/white science equipment, gold highlights and expressive faces of the reference characters. Create a NEW atlas, do not alter reference. Layout: exactly 4 equal columns and 3 equal rows on a completely transparent background, all 12 cells the same size, with wide transparent gutters; each full character isolated wholly inside its own cell, no overlaps, consistent size and lighting across each row. Row 1: four successive subtly different squash-and-stretch frames of a cute luminous green laboratory slime with a rounded translucent jelly body, big mischievous eyes, teal highlights and bubbles trapped inside. Row 2: four successive walking/charging frames of the SAME compact white-and-turquoise lab security robot with two articulated legs, chunky boots, little mechanical arms, glossy dark face screen and amber eyes, clear sideways game silhouette facing left. Row 3: four successive hover/attack frames of the SAME imposing spherical Element Core guardian machine, silver and purple armour panels surrounding a large glowing violet crystal core, gold brackets, two floating articulated gauntlets, expressive amber eyes; whole silhouette inside each cell. Avoid text, letters, labels, borders, scenery, shadows outside cells, repeated panels of unrelated designs, backgrounds or watermarks. These are production sprites viewed fairly small: strong readable silhouettes, detailed material highlights, cute adventurous tone, full bodies including feet/floating hands. Frames must show visible motion changes in body shape or articulated parts without changing identity. Transparent alpha is required.
