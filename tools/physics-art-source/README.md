# Physics Force Lab illustrated artwork

The built-in image-generation tool created eight transparent 4 × 3 pose sheets and six paired environment illustrations using the approved v4.9 cover as the rendering reference. The v4.6 cast sheet supplied secondary robot identities. No image API key, paid CLI workflow, new dependency or runtime generation is required.

`prompts.json` records the prompt set and the selected source/reference paths. `characters/{player,professor,helper,glitch,drone,magnetBot,boss,maintenance}.webp` preserve the selected pose sheets as lossless WebP, including alpha. These are build sources; browsers only download the packed runtime atlases. The original vector rig file retains the established clip timing and body-bound definitions.

Run `node tools/build-physics-characters.cjs` from the repository root to repack the eight `apps/web/public/games/physics-force-lab/assets/characters/*.png` atlases, metadata and v5.0 cast contact sheet. Sharp is already a repository dependency. The builder extracts complete alpha-connected silhouettes, associates them with their source cells, retains antialiased edges, scales every pose of a character consistently and aligns the feet to the existing anchor. This avoids clipping wide poses at approximate generated grid boundaries. Drawn poses carry limb movement and actions; small secondary offsets add hover, breathing and recoil. The `physics-illustrated-poses.cjs` table maps those poses onto all 40 existing animation clips and 227 atlas frames. Runtime image dimensions and total decoded atlas allocation remain unchanged.

The environment panels were cropped at their halfway split and centre-cropped to 1024 × 576 without stretching, then encoded as quality-88 WebP. Their twelve final runtime files live under `apps/web/public/games/physics-force-lab/assets/worlds/`: workshop, motion, gravity, friction, energy, machines, circuit, magnet, waves, pressure, space and core. The final encoded backgrounds are the repository source of truth; no image service is needed to build or deploy them. Sharp performs cropping/packing/encoding only and does not redraw the artwork.

The unchanged `thumb.png` is the approved reference. Existing backgrounds and procedural fallback characters remain available if new art cannot load. `world-art.js` selects the new environment for every existing route reference, cover-crops it to the viewport, limits the image cache to three unique locations and suppresses atmospheric motion when reduced motion is enabled. Foreground platform coordinates and all collisions remain defined by the game runtimes.
