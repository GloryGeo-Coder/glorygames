# Stack Tower: Skyline Adventure — Challenges and Styles

Players can choose the existing endless adventure, a daily construction challenge or a 90-second timed objective. Daily targets are determined by the UTC date and reset at 00:00 UTC. Daily wins are recorded once per date; retries remain available. Timed runs require both 12 floors and five perfect drops, and the clock pauses with the game. Missing or narrowing the tower still ends a run.

Five block and tower palettes include Classic, Sunset (10 floors), Aurora (20 floors), Golden (one daily win) and Neon (one timed win). The selected palette is applied to the tower throughout play. The existing best-height key is retained; daily dates, timed wins and selected style use a separate local-storage key. Storage failures leave gameplay available in the current tab.

The release includes the tested mobile-rotation minimum-width fix from PR #94. It preserves the stage contracts, repairs, Focus Mode, sound controls, score bridge and original skyline artwork. Only the changed game, tests, workflow and information-page files are included.
