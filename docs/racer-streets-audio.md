# High Speed Racer — streets and audio update (v0.16)

Traffic and rivals now face the same forward direction as the player, including initial placement, AI updates and restarts. Their relative movement, collision rules and overtaking logic are preserved.

The original six routes remain in their original order and retain their distances, speed limits and difficulty settings. Six additional streets add authored GLB landmarks: Harbour Afterdark, Old Town Boulevard, Industrial Ring, Neon Tunnel, Airport Express and Grand Prix Skyway. The menu offers the full twelve-street campaign or a three-lap race on any individual street. A single-street win does not grant the full campaign's 5,000-point completion bonus. Change Street returns to the route menu after a race.

Four original instrumental compositions provide route background music. Nine original WAV files supply layered low/high engine pulses, road air, Nitro, gear shifts, passing, impact, pickup and finish cues. The engine mix responds to speed, virtual gear, Nitro and the selected garage vehicle. These are original synthesized sound designs, not recordings of named manufacturers' engines. Existing audio files are unchanged.

Audio is unlocked by a user gesture. Music, engine and effects have separate volume controls; preferences use the additive `high-spead-racer-audio-v1` key. Race pause/backgrounding suspends audio, resume restores it, mute works across all buses, and route changes crossfade music. Decoded music is capped at two cached tracks. Late downloads cannot restart paused/disposed music. Failed audio downloads do not interrupt gameplay.

The dedicated game tab, existing garage/save key, ownership IDs, upgrades, controls, scores, checkpoints, mobile graphics limits and fullscreen integration remain. Existing vehicle/road/skyline GLBs, thumbnails and legacy sounds are byte-identical. New street scenery is loaded on demand. No database, platform layout or Cloudflare configuration changes are required.

## Validation

Run from the repository root:

```sh
node --test apps/web/scripts/high-speed-racer-*.test.*
node --test apps/web/scripts/game-tab-score.test.mjs apps/web/scripts/game-tab-ui.test.mjs
node --test tests/*.test.mjs tests/*.test.cjs
cd apps/web
node --import tsx --test scripts/game-tabs.test.tsx scripts/sky-temple-launch.test.tsx
npx opennextjs-cloudflare build
```

Actual PlayCanvas/NullGraphicsDevice tests check rival and traffic orientation, real GLB imports for all new streets, twelve-route completion, single-street scoring, controls, collisions, restart and save retention. Audio tests cover gesture unlock, gear/pitch changes, pause/resume, mute, bounded music caching, late loads, volume preferences and failures. Asset checks verify geometry budgets, references, PCM loop boundaries, audio hashes and headroom. All thirteen new sound files also decode successfully with ffmpeg.

NullGraphicsDevice and audio adapters do not measure GPU appearance, physical touch ergonomics or perceived sound quality. Use `?scores=0` at the direct game URL for a score-free device check, and verify the visible car directions, new streets and audio mix after deployment.

Generate the new content with `tools/build-racer-street-assets.py` (standard-library Python) and `tools/build-racer-audio.py` (NumPy and ffmpeg). Existing assets are not regenerated by either script.

Deploy through the existing feature-branch → PR → main → Cloudflare pipeline. Roll back by reverting the feature merge; saved garage data and old assets remain compatible.
