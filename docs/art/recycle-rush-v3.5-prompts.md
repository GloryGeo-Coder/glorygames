# Recycle Rush v3.5 — arcade art prompts

Generated with the built-in image_gen tool. Existing backgrounds, Circuit/Grime story atlases, material sprites and thumbnail remain unchanged. The deterministic packer is `apps/web/scripts/recycle-arcade-pack.cjs`. It extracts equal RGBA cells, uses a constant scale per boss row with a shared baseline, and encodes new WebP assets. Source and final hashes are recorded in `assets/arcade/manifest.json`.
