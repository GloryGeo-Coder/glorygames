# Recycle Rush v3.1 art generation

Generated with the built-in `image_gen` tool. The user-supplied Recycle Rush thumbnail was an identity/style reference, not an edit target. New files were saved under `apps/web/public/games/recycle-rush/assets/animated/`; existing artwork was not overwritten. Original generation SHA-256 values, output hashes and byte counts are in that directory's `manifest.json`.

`apps/web/scripts/recycle-sprite-pack.cjs` extracts equal cells, crops item cells to the largest connected alpha-component bounds, normalises character scale/ground alignment and packs RGBA WebP outputs. It does not redraw art. Re-run with the four original generated PNG paths:

```bash
NODE_PATH=apps/web/node_modules node apps/web/scripts/recycle-sprite-pack.cjs circuit.png grime.png items.png prepared.png
```

The original generation sheets are the four images returned with this build. Compiled assets are committed to the repository and do not require a generation service at runtime.
